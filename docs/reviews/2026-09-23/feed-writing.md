# Feed writing correction — September 23, 2026

The September 20 fix protected counts but made stories too generic. Of four posts generated afterward, three were deterministic fallbacks and one opened with “The journey continues.” The old code did not store fallback reasons, so the exact original failures cannot be recovered. Live reproduction exposed rejection of otherwise accurate expanded facts, conjunctions in trophy counts, punctuation inside quoted trophy names, and empty optional fields.

Changes: supply a verified named unlock and its platform objective on ordinary updates, prioritize rare/high-value unlocks, lead with the actual accomplishment, accept exact expanded facts as well as placeholders, handle optional empty fields, preserve highlight details in fallback, and log fallback reasons. Counts, title requirements, pagination, snapshot verification, and historical-import labeling remain intact. Literal invented numbers and mismatched counts still fail validation. Narrative objective paraphrases are constrained by instructions, not a mathematical proof of semantic accuracy.

Four real records were reconstructed from snapshots and achievement rows: Thieves Guild Guildmaster, Dark Brotherhood Silencer, Arena Grand Champion, and Faithful Heir (thirteen royal arms). All four final live AI previews passed validation. All 38 service tests passed, including new regressions for empty optional facts, expanded values, quote punctuation, incorrect counts, required highlights, and objective selection. Backup and preview records for posts 550–553 are stored locally in output/feed-writing/previews.json. This is a backend-only change; no mobile release or database migration is required.
